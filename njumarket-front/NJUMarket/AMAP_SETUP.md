# 高德地图API配置说明

## 1. 获取高德地图API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册/登录账号
3. 进入控制台 -> 应用管理 -> 我的应用
4. 创建新应用，选择"Web端(JS API)"
5. 获取 Key（API Key）

## 2. 配置API Key

在 `public/index.html` 文件中，找到以下代码：

```html
<script type="text/javascript" src="https://webapi.amap.com/maps?v=2.0&key=YOUR_AMAP_KEY&plugin=AMap.Geocoder,AMap.PlaceSearch"></script>
```

将 `YOUR_AMAP_KEY` 替换为你的实际API Key。

## 3. 功能说明

### 地址选择器功能
- **地图选择**：用户可以在地图上点击选择位置
- **标记拖拽**：用户可以拖拽标记到指定位置
- **地址搜索**：用户可以搜索地址，自动定位
- **自动获取经纬度**：选择位置后自动获取经纬度坐标
- **逆地理编码**：根据经纬度自动获取详细地址信息

### 使用场景
1. **创建地址时**：用户可以通过地图选择位置，自动填充地址和经纬度
2. **编辑地址时**：显示现有地址位置，可以在地图上调整
3. **发布商品时**：选择商品所在位置，自动获取经纬度

## 5. 注意事项

1. **API Key安全**：不要将API Key提交到公开仓库
2. **域名限制**：可以在高德控制台设置API Key的域名白名单
3. **HTTPS要求**：生产环境建议使用HTTPS

## 6. 备用方案

如果不想使用高德地图，也可以考虑：
- **百度地图API**：类似的功能和配置
- **腾讯地图API**：类似的功能和配置

只需要修改 `AddressMapPicker.vue` 组件中的地图初始化代码即可。
