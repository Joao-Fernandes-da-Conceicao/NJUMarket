\section{项目经历}

\datedsubsection{\textbf{NJUMarket 南大集市（校园二手交易平台）}}{}

技术栈：Spring Boot 3、Spring Cloud、PostgreSQL + pgvector、Elasticsearch、Redis、RabbitMQ、LangChain4j、Docker、Nacos、Zipkin\\

基于微服务架构的校园二手交易平台，集成 AI Agent 智能推荐和语义搜索功能，支持商品发布、订单管理、实时消息等核心功能

\begin{itemize}[leftmargin=*]
	\item 基于 Spring Cloud 构建微服务架构，使用 Nacos 实现服务注册与发现，通过 OpenFeign 实现服务间调用，使用 Spring Security 实现统一鉴权
	\item 设计库存扣减链路：Redis 分布式锁 + 数据库悲观锁 + 条件更新，结合数据库事务确保库存一致性，防止超卖
	\item 接入 Elasticsearch 全文检索，配置 IK 分词器支持中文分词；使用 PostgreSQL + pgvector 实现商品语义搜索，支持自然语言查询
	\item 统一搜索过滤逻辑：在 ES 和 AI 语义搜索中统一过滤库存为 0 的商品和用户自己的商品，保证搜索结果真实可售
	\item 基于 LangChain4j 实现 AI Agent，通过 Function Calling 让用户对话式描述需求，系统自动匹配最适合的商品并生成推荐理由
	\item 自研 WebSocket 消息服务：买家咨询/卖家报价即时推送，配合 RabbitMQ 异步消息投递、离线 ACK 与消息持久化，保障交易沟通连续性
	\item 配置 Docker Compose 一键部署所有服务，集成 Zipkin 链路追踪和 Prometheus/Grafana 监控，支持快速部署与运维
\end{itemize}
