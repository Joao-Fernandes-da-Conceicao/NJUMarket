# 南大集市 NJUMarket v1.0 总结

## 一、版本概述
- 目标：完成“发布-浏览-下单-支付-发货-收货-退款/退货-消息联系”等核心流程的可用闭环。
- 状态：v1.0 已发布（开发环境端口：前端 8081，后端 8080）。

## 二、主要功能
- 账号体系：登录/注册、资料编辑、头像上传。
- 商品：发布、编辑、上下架、浏览、搜索/筛选、分类、成色、价格区间。
- 订单：创建、支付、发货、确认收货、取消、退款/退货（通过/拒绝/历史展示）。
- 消息：买卖双方对话，列表与聊天窗口（已组件化），支持多行输入（Ctrl+Enter 发送）。

## 三、前端实现要点
- 技术栈：Vue 3 + Element Plus + Vue CLI。
- 统一组件：
  - `UnifiedButton`（药丸形、按类型定制默认配色）、`UnifiedTag`（药丸形）
  - `UnifiedSelect`（药丸形触发器 + 统一弹窗）、`UnifiedInput`（单行药丸/多行圆角，紫色边框）
- 业务规则集中：`utils/orderRules.js`（下单/支付/发货/取消/联系等前置校验）。
- 响应式断点：集中于 `config/breakpoints.js`，JS 与 CSS 同源常量。
- 列表/分页：`components/common/Pagination.vue` + 统一样式 `styles/pagination.css`。
- 页面结构优化：
  - 商品详情/发布商品/创建订单等支持宽屏分栏。
  - 订单详情分栏：左（订单+商品）/右（卖家/买家/物流/退货/操作）。
  - 消息页组件化：`ConversationList` + `ChatWindow`，样式独立、可维护性提升。
- 统一视觉：页面背景、卡片圆角、按钮药丸、标签药丸、输入边框/对齐策略统一；标题改为“南大集市 NJUMarket”。

## 四、后端实现要点
- 订单时间写入：`payTime`、`shippingTime`、`deliveryTime` 等字段更新与映射。
- 订单快照图片：仅保存首图链接（逗号分隔字符串场景兼容）。
- API 分层：DTO 映射、Service 校验、Repository 访问；日志增强。

## 五、重构与可维护性
- 统一拦截层（orderRules）：减少分散条件判断，保证前后端逻辑一致。
- 统一样式与组件：Button/Tag/Select/Input，减少重复样式与局部覆盖。
- 消息页解耦：列表与窗口拆分组件，移除样式交叉影响（scoped）。
- 端口与标题：前端端口恢复 8081；浏览器标题统一配置于 `vue.config.js`。

## 六、已知限制/待办（v1.1+）
- 消息实时化：WebSocket 推送、未读数实时更新、断线重连。
- 大数据优化：消息列表虚拟滚动、会话分页/上拉加载、图片/头像懒加载。
- 更细粒度的权限/可见性控制（订单/会话）。
- 单元测试：`orderRules`、消息发送与滚动策略、关键组件 snapshot/交互测试。
- 国际化与无障碍：i18n、多语言日期/货币、ARIA 标签完善。

## 七、升级指南（运维）
- 前端：`npm install && npm run build`，静态资源托管到服务端；开发环境 `npm run serve`（端口 8081）。
- 后端：执行数据库迁移脚本（时间字段/索引），重启服务（默认端口 8080）。
- 静态图标：替换 `public/favicon.ico` 与页面中使用的 `src/assets/logo.*` 引用。
