# 数据库初始化说明

## 文件说明

- `init.sql`: 数据库初始化脚本，包含所有表结构和初始数据

## 数据库表结构

### 核心业务表

1. **users** - 用户表
   - 存储用户基本信息（用户ID、手机号、注册时间、账户状态）
   - 一个手机号只能绑定一个账号

2. **user_profiles** - 用户档案表
   - 存储用户详细信息（昵称、头像、信用分、评分、VIP等级等）
   - 与用户表一对一关系

3. **contact_info** - 联系方式表
   - 存储用户的各种联系方式（电话、邮箱、微信、QQ）
   - 支持加密存储，保护用户隐私

4. **commodities** - 商品表
   - 存储商品信息（标题、描述、价格、库存、位置等）
   - 包含商品状态管理和统计信息

5. **orders** - 订单表
   - 管理买卖双方的交易订单
   - 支持完整的订单状态流转

6. **messages** - 消息表
   - 用户之间的站内消息通信
   - 支持多种消息类型

### 管理功能表

7. **complaints** - 投诉表
   - 处理用户之间的投诉和纠纷
   - 支持证据文件存储

8. **audit_records** - 审核记录表
   - 记录商品审核的详细信息
   - 支持自动和人工审核

9. **ban_records** - 封禁记录表
   - 记录用户封禁信息
   - 支持多种封禁类型（临时、永久、设备、手机、实名）

### 统计分析表

10. **user_activity_records** - 用户活动记录表
    - 记录用户的各种活动行为
    - 用于数据分析和用户行为追踪

11. **promotions** - 促销活动表
    - 管理各种促销活动和优惠券
    - 支持多种促销类型

12. **data_statistics** - 数据统计表
    - 存储各种统计数据和分析结果
    - 支持多维度、多周期统计

## 使用方法

### 1. 创建数据库

```sql
CREATE DATABASE njumarket CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE njumarket;
```

### 2. 执行初始化脚本

```bash
mysql -u username -p njumarket < init.sql
```

或在MySQL客户端中：

```sql
SOURCE /path/to/init.sql;
```

### 3. 验证安装

```sql
-- 查看所有表
SHOW TABLES;

-- 查看表结构示例
DESCRIBE users;
DESCRIBE commodities;

-- 查看初始数据
SELECT * FROM users;
SELECT * FROM commodities;
```

## 注意事项

1. **字符集**: 使用 `utf8mb4` 字符集，支持完整的Unicode字符
2. **外键约束**: 启用了外键约束，确保数据完整性
3. **索引优化**: 为常用查询字段添加了索引
4. **数据类型**: 
   - 价格使用 `DECIMAL(10,2)` 确保精度
   - 时间使用 `DATETIME` 类型
   - 布尔值使用 `TINYINT(1)`
   - 长文本使用 `TEXT` 类型
5. **默认值**: 为必要字段设置了合理的默认值
6. **注释**: 所有表和字段都有中文注释说明
